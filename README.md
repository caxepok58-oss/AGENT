# shorts-agent

A trend-aware AI agent that researches what is currently working on YouTube,
writes a short-form script, produces a vertical video with voiceover and
burned-in captions, and publishes it to YouTube with SEO metadata.

Full documentation is in [`docs/`](docs/). Start with [SETUP.md](docs/SETUP.md).

> **Read [docs/POLICY.md](docs/POLICY.md) before publishing anything.** Automated
> uploading touches YouTube's spam, authenticity and synthetic-media policies.
> This project defaults to uploading as **private** with a human review step for
> that reason.
